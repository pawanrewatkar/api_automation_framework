# API Automation Framework

A **reusable API automation framework** built with **Java, REST Assured, TestNG, and Maven**.

Created as a **self-driven R&D project** with the basic framework setup ready to reuse. Simply add your **API classes, test cases, payloads, and validations**—no need to build the foundation from scratch.

### Tech Stack

**Java | REST Assured | TestNG | Maven**

### Reuse

```bash
git clone https://github.com/pawanrewatkar/api_automation_framework.git
```

Replace the demo implementation with your own APIs and test scenarios.

**Goal:** Provide a simple, maintainable foundation for API automation projects.
