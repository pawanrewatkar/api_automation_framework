# API Automation Framework

A **reusable API automation framework** built with **Java, REST Assured, TestNG, and Maven**.

This project was created as a **self-driven R&D initiative** to provide a ready-to-use framework foundation for API testing. The basic setup is already available, so you can reuse the framework by adding your own **API classes, test cases, request payloads, validations, and configurations**.

## 🛠️ Tech Stack

* **Java**
* **REST Assured**
* **TestNG**
* **Maven**

## ✨ Key Features

* ♻️ Reusable API automation structure
* 🔗 REST API testing
* 🧪 Request & response validation
* 🔧 Easy to extend with new APIs and test cases
* 📦 Maven-based setup

## 🚀 Reuse

Clone the repository, remove the demo API classes/tests, and add your own API endpoints and test scenarios.

```bash
git clone https://github.com/pawanrewatkar/api_automation_framework.git
```

**Goal:** Provide a simple, maintainable, and reusable foundation for starting API automation projects without setting up the framework from scratch.
